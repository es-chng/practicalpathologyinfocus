Write an article

Choose an article type and fill in the form. Then download the article file and add it to the _articles/ folder of the repository (on GitHub: Add file → Upload files). Nothing you type leaves this page.

Designing an article type? Preview a schema here

Write or paste a schema below, or start from an existing one. The form switches to it as you type, and any rule it breaks is listed. Nothing is saved: when it is right, download the schema file and add it to _data/ in the repository. (Starting from an existing schema shows its content without the comments in its file.)
